Collega un telefono o un PC

Da fare una volta sola per ogni telefono, tablet o computer, collegato alla stessa rete Wi-Fi del negozio.

1. Scarica e installa il certificato

{{ qr_certificato }}

{{ url_certificato }}

Il certificato permette al telefono di riconoscere Racoonix e proteggere i dati con la crittografia.

Android
  1. Inquadra il QR: il file racoonix-ca.crt viene scaricato.
  2. Impostazioni → Sicurezza → Crittografia e credenziali (o Altre impostazioni di sicurezza) → Installa un certificato → Certificato CA → conferma l'installazione.
  3. Scegli il file dalla cartella Download.

Se non trovi la voce, cerca "certificato" nelle Impostazioni. Serve un blocco schermo (PIN o impronta).

iPhone
  1. Inquadra il QR con la fotocamera e consenti il download del profilo.
  2. Impostazioni → Profilo scaricato → Installa.
  3. Impostazioni → Generali → Info → Impostazioni attendibilita' certificati → attiva il certificato.
Computer (Windows, Mac, Linux)

Apri sul computer l'indirizzo sotto il QR per scaricare il certificato, poi:

  • Windows: doppio clic sul file → Installa certificato → Utente corrente → "Colloca tutti i certificati nel seguente archivio" → Autorita' di certificazione radice attendibili → Fine.
  • Mac: doppio clic sul file → si apre Accesso Portachiavi → doppio clic sul certificato → Fidati → Fidati sempre.
  • Linux: sudo trust anchor racoonix-ca.crt (Arch, Fedora) oppure copialo in /usr/local/share/ca-certificates/ e lancia sudo update-ca-certificates (Ubuntu, Debian).

Firefox puo' usare un archivio suo: se mostra ancora l'avviso, importalo da Impostazioni → Privacy e sicurezza → Certificati → Mostra certificati → Autorita' → Importa.
